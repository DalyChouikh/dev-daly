# Olive / Remotion

See [the study README](../README.md) for scope, assets, verification, and both
frameworks. Run `bun install --frozen-lockfile`, then `bun run dev` for the interactive Studio.

`OliveStudy` is the 240-frame, 30fps source study. `OliveReducedMotion` uses the
same chapters with static cuts. Source and proof stills are the deliverables;
no rendered MP4 was requested.
